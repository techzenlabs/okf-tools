# Awkward description

Descriptions in this estate were derived from lead paragraphs, so they carry
whatever punctuation the paragraph carried: pipes, backticks, an opening
bracket whose link never closed, and a bare `<` that is a comparison rather
than a tag. Rendered as markdown, none of them may break the listing that
holds them.
