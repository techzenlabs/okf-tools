# ExecPlan

`PLANS.md` sorts before `implement.md` in bytes because uppercase letters
sort before lowercase in ASCII, and its title `ExecPlan` sorts before
`Implement` too — so filename bytes, title order and Hugo's
weight/date/linkTitle default all list this page first, and only
`RelPermalink` ascending lists it second. Whichever key a listing sorts
by, this page is the tell.
