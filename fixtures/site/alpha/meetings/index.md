# Meetings

A month-grouped listing, and the A1/B2 cancellation this fixture exists for.
`[index] group_by_month` makes okf-index write the same three links Hugo
knows about, under two month headings it added itself. The href sets match
exactly, so the set-equality proof passes and the template used to replace
the block — throwing away both headings and telling a reader nothing about
when anything happened, with no gate anywhere the wiser.

The `<h2>` guard is what stops that. A heading okf-index put here that is
not `Sections` means the block carries something the built navigation
cannot reproduce, so this page must render the generated markdown verbatim,
month headings and all.
